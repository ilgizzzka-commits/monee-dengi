# Деньги Monee

Личное приложение: картина денег бизнеса (счета, товар, долги, прибыль) из своей таблицы на Google Диске — только чтение, цифры остаются в браузере.

## Открытые данные (обновляются сами)
- `data.json` — курсы ЦБ (юань, доллар, евро) и производственный календарь РФ. Только общие открытые данные, без ключей и без личного.
- `fetch.py` собирает их, `.github/workflows/update.yml` запускает по расписанию: каждый день 06:00 и по будням 15:00 по Уфе. Ручной запуск: Actions → «Обновить данные» → Run workflow.
